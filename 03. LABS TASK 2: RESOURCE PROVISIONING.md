# 3. LABS Task 2: Resource Provisioning

## 📘 Objective

Deploy and configure required cloud resources.

## ⚙️ Step-by-Step Instructions

### Step 1: Deploy Virtual Machines

1. Go to **Resource Groups**.
2. Select **Add Resource**.
3. Select **Virtual Machine**.
4. Configure VM settings:

   * Name
   * Size
   * OS
5. Select networking:

   * VNet
   * Subnet
6. Configure storage and disks.
7. Review and create the virtual machine.

> **Tip:** Choose appropriate VM sizes for workload requirements.

### Step 2: Configure Storage Accounts

1. Create a **Storage Account**.
2. Choose a replication strategy:

   * LRS
   * GRS
   * RA-GRS
3. Configure the access tier.
4. Set up containers/file shares.
5. Configure the firewall and access control.

> **Tip:** Use separate storage accounts for different data classifications.

### Step 3: Set Up Database Services

1. Create a **Database Server** (SQL Server, PostgreSQL, etc.).
2. Configure authentication:

   * SQL
   * AD
3. Set firewall rules.
4. Create databases.
5. Configure backup policies.
6. Enable encryption.

> **Important:** Always enable transparent data encryption (TDE) for databases.

### Step 4: Configure Load Balancers

1. Create a **Load Balancer**.
2. Configure backend pools.
3. Set up health probes.
4. Define load balancing rules.
5. Configure SSL/TLS termination.
6. Test failover scenarios.

> **Tip:** Distribute traffic across availability zones for redundancy.

### Step 5: Deploy Application Services

1. Create an **App Service** or **Container Service**.
2. Configure the runtime stack.
3. Set up deployment slots.
4. Configure auto-scaling rules.
5. Enable monitoring and diagnostics.

> **Tip:** Use deployment slots for blue-green deployments.
