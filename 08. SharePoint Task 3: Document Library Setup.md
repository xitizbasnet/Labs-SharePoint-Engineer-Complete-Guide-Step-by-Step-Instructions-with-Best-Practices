# 8. SharePoint Task 3: Document Library Setup

## 📘 Objective

Create and configure document libraries with proper structure and governance.

## ⚙️ Step-by-Step Instructions

### Step 1: Define Library Requirements

1. Identify document types and categories.
2. Define retention requirements.
3. Identify storage needs.
4. Plan the folder structure.
5. Determine versioning needs.
6. Get stakeholder input.

> **Tip:** Think about future scalability when planning the structure.

### Step 2: Create Document Library

1. Navigate to **Site Contents**.
2. Select **Create New** > **Document Library**.
3. Name the library (for example, `Project Documents`).
4. Add a description.
5. Choose a document template if needed.
6. Create the document library.
7. Configure the settings.

> **Tip:** Use descriptive library names that indicate the content type.

### Step 3: Configure Library Settings

1. Go to **Library Settings**.
2. Enable or disable versioning.
3. Configure check-out settings.
4. Set up item creation permissions.
5. Enable the recycle bin.
6. Configure content approval if needed.
7. Enable compliance settings.

> **Important:** Enable versioning for critical documents.

### Step 4: Create Content Types

1. Navigate to **Content Types** in **Library Settings**.
2. Create a new content type, for example:

   * `Project Charter`
   * `Meeting Minutes`
3. Add custom columns.
4. Configure templates.
5. Publish the content type.
6. Add the content type to the library.

> **Tip:** Content types provide structure and enforce metadata.

### Step 5: Set Up Metadata and Columns

1. Add columns, including:

   * Text
   * Choice
   * Date
   * Person
   * Lookup
   * Etc.
2. Define column requirements.
3. Create choice sets or lookups.
4. Configure default values.
5. Organize columns logically.
6. Hide unnecessary columns from views.

> **Tip:** Metadata enables better organization and search.

### Step 6: Create Views

1. Create list views for different purposes, for example:

   * `By Project`
   * `By Status`
   * `By Owner`
2. Configure filters and sorting.
3. Group items appropriately.
4. Set up aggregations.
5. Test usability from the user perspective.

> **Tip:** Views help users find content efficiently.

---

## 📋 Best Practices - SharePoint Task 3

9. Implement consistent metadata across related libraries.
10. Use managed metadata terms instead of free-form choices.
11. Enable versioning for all document libraries.
12. Implement check-in/check-out for collaborative editing.
13. Use content types to enforce document structure.
14. Configure version history retention based on compliance needs.
15. Set up item-level permissions only when necessary.
16. Create multiple views to serve different user needs.
17. Use column formatting to improve data visualization.
18. Implement retention labels for automatic deletion/archival.
19. Enable coauthoring for collaborative document editing.
20. Configure sync settings for offline access.
21. Use folders sparingly; rely on metadata instead.
22. Create templates for commonly used documents.
