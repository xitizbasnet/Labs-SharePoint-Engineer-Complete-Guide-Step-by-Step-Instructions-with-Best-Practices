# 2. LABS Task 1: Setting Up Lab Environment

## 📘 Objective

Establish foundational lab infrastructure.

## ⚙️ Step-by-Step Instructions

### Step 1: Assess Requirements

1. Review project specifications.
2. Identify resource needs.
3. Check compliance requirements.
4. Verify available budget and timeline.

### Step 2: Create Resource Group

1. Log into Azure Portal (or your cloud platform).
2. Navigate to **Resource Groups**.
3. Click **Create**.
4. Enter the resource group name (for example, `LAB-RG-001`).
5. Select the appropriate region.
6. Review and create.

> **Tip:** Create meaningful naming conventions (for example, `ENV-RESOURCETYPE-NUMBER`).

### Step 3: Configure Networking

1. Go to **Virtual Networks**.
2. Create a new VNet.
3. Define the address space (for example, `10.0.0.0/16`).
4. Create subnets:

   * `10.0.1.0/24` for frontend
   * `10.0.2.0/24` for backend
5. Configure Network Security Groups (NSGs).

> **Important:** Always use private IP ranges and implement network segmentation for security.

### Step 4: Set Up Monitoring & Logging

1. Create a **Log Analytics Workspace**.
2. Configure **Application Insights**.
3. Set up **Activity Logs**.
4. Enable diagnostic logging for all resources.
5. Configure alerts for critical metrics.

> **Important:** Monitor from day one; don't add monitoring retrospectively.

### Step 5: Document Environment

1. Create documentation in OneNote or Wiki.
2. Record resource names, IPs, and configurations.
3. Document access procedures.
4. Create architecture diagrams.
5. Share with the team.

> **Tip:** Use consistent documentation formats across all labs.
