# 2. LABS TASK 1: SETTING UP LAB ENVIRONMENT

> **Objective:** Establish foundational lab infrastructure.

## Step-by-Step Instructions

### Step 1: Assess Requirements

Review project specifications, identify resource needs, check compliance requirements, verify available budget and timeline.

### Step 2: Create Resource Group

1. Log into Azure Portal (or your cloud platform) ® Navigate to Resource Groups ® Click **'Create'** ® Enter resource group name (e.g., `'LAB-RG-001'`) ® Select appropriate region ® Review and create.

> **Best Practice:** Create meaningful naming conventions (e.g., `ENV-RESOURCETYPE-NUMBER`).

### Step 3: Configure Networking

1. Go to **Virtual Networks** ® Create New VNet ® Define address space (e.g., `10.0.0.0/16`) ® Create subnets (e.g., `10.0.1.0/24` for frontend, `10.0.2.0/24` for backend) ® Configure Network Security Groups (NSGs).

> **Best Practice:** Always use private IP ranges; implement network segmentation for security.

### Step 4: Set Up Monitoring & Logging

1. Create Log Analytics Workspace ® Configure Application Insights ® Set up Activity Logs ® Enable diagnostic logging for all resources ® Configure alerts for critical metrics.

> **Best Practice:** Monitor from day one; don't add monitoring retrospectively.

### Step 5: Document Environment

1. Create documentation in OneNote or Wiki ® Record resource names, IPs, and configurations ® Document access procedures ® Create architecture diagrams ® Share with team.

> **Best Practice:** Use consistent documentation formats across all labs.
