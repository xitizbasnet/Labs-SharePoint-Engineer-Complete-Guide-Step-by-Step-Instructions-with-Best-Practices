# 3. LABS TASK 2: RESOURCE PROVISIONING

> **Objective:** Deploy and configure required cloud resources.

## Step-by-Step Instructions

### Step 1: Deploy Virtual Machines

1. Resource Groups ® Add Resource ® Virtual Machine ® Configure VM settings (name, size, OS) ® Select networking (VNet, subnet) ® Configure storage and disks ® Review and create.

> **Best Practice:** Choose appropriate VM sizes for workload requirements.

### Step 2: Configure Storage Accounts

1. Create Storage Account ® Choose replication strategy (LRS, GRS, RA-GRS) ® Configure access tier ® Set up containers/file shares ® Configure firewall and access control.

> **Best Practice:** Use separate storage accounts for different data classifications.

### Step 3: Set Up Database Services

1. Create Database Server (SQL Server, PostgreSQL, etc.) ® Configure authentication (SQL/AD) ® Set firewall rules ® Create databases ® Configure backup policies ® Enable encryption.

> **Best Practice:** Always enable transparent data encryption (TDE) for databases.

### Step 4: Configure Load Balancers

1. Create Load Balancer ® Configure backend pools ® Set up health probes ® Define load balancing rules ® Configure SSL/TLS termination ® Test failover scenarios.

> **Best Practice:** Distribute traffic across availability zones for redundancy.

### Step 5: Deploy Application Services

1. Create App Service or Container Service ® Configure runtime stack ® Set up deployment slots ® Configure auto-scaling rules ® Enable monitoring and diagnostics.

> **Best Practice:** Use deployment slots for blue-green deployments.

## 3 BEST PRACTICES - LABS Task 2

4. Use managed services instead of IaaS when possible (reduced operational overhead)
5. Implement auto-scaling policies based on realistic load metrics
6. Configure redundancy across multiple availability zones
7. Enable encryption at rest and in transit for all data
8. Implement network isolation with NSGs and subnet segmentation
9. Use service endpoints or private endpoints for internal communication
10. Document resource configuration in version control
11. Regularly review resource utilization to optimize costs
