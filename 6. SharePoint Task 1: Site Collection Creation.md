# 6. SharePoint Task 1: Site Collection Creation

## 📘 Objective

Create and configure a new SharePoint site collection.

## ⚙️ Step-by-Step Instructions

### Step 1: Plan Site Collection Architecture

1. Identify business requirements.
2. Define the site structure, including the hub model and site collections.
3. Plan the URL structure.
4. Identify the owner and contributors.
5. Document governance policies.

> **Tip:** Use hub sites for organizational grouping of related sites.

### Step 2: Create Site Collection

1. Access **SharePoint Admin Center**.
2. Navigate to **Sites** > **Active Sites**.
3. Select **Create New Site**.
4. Select the site type:

   * Team
   * Communication
5. Configure the site name (for example, `Marketing Team`).
6. Define the URL path.
7. Select the language.
8. Proceed.

> **Tip:** Use meaningful, descriptive site names that reflect the business purpose.

### Step 3: Configure Site Collection Settings

1. Go to **Settings** > **Site Collection Settings**.
2. Configure the **Primary Administrator**.
3. Set the **Secondary Administrator**.
4. Configure the **Site Collection Quota**.
5. Set the storage limit.
6. Enable or disable features.

> **Tip:** Set appropriate storage quotas based on content requirements.

### Step 4: Set Up Site Navigation

1. Edit the site navigation menu.
2. Add links to key libraries and lists.
3. Create a hierarchical structure.
4. Configure the mega menu if needed.
5. Test navigation from different devices.

> **Tip:** Intuitive navigation improves user adoption.

### Step 5: Configure Site Permissions

1. Define permission groups:

   * Owners
   * Members
   * Visitors
2. Assign users to groups.
3. Configure inheritance settings.
4. Set up SharePoint groups.
5. Test access permissions.

> **Tip:** Use SharePoint groups instead of individual permissions.
